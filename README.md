# Lost & Found Management System

A simple Lost & Found Management System developed using HTML, CSS and JavaScript. The project demonstrates the use of Git and GitHub for version control and collaborative software development.

## Features

* Add Lost Item
* Add Found Item
* Display Lost and Found Items
* Search Item by ID
* Delete Item Record
* Store item data using browser localStorage

## Technologies Used

* HTML
* CSS
* JavaScript
* Git
* GitHub
* Browser localStorage

## Branching Strategy

* `main` - Stable and production-ready code
* `develop` - Integration branch for completed features
* `feature/add-lost-item` - Add Lost Item functionality
* `feature/search-item` - Search Item functionality

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Use the Lost & Found system to add, search, display and delete item records.

## Git Workflow

The project follows a simplified Git Feature Branch Workflow. Features are developed separately in feature branches, merged into the `develop` branch for integration and testing, and finally merged into the `main` branch for the stable version.
